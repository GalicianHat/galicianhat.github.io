Comienza la aventura

Abre la forja en unos minutos.

Necesitas Python 3.10 o posterior. Descarga la versión preliminar, descomprímela y ejecuta GimliForge desde una terminal. Se abrirá en 127.0.0.1:8765.

  1. Descarga y descomprime el paquete.
  2. Abre la carpeta GimliForge en una terminal.
  3. Ejecuta el comando de tu sistema.
  4. Prueba el archivo datos_entrada/demo.json.
Descargar versión preliminar ↓Ver repositorio ↗

El repositorio público todavía muestra la versión 1. Esta descarga es una vista previa de la 2.0, no una versión final.

# Dentro de la carpeta GimliForge
py GimliForge.py

# La aplicación abrirá el navegador
# Para cerrarla: Ctrl+C

Para generar PDF se necesita además pdflatex. El archivo LaTeX puede descargarse sin instalarlo. La versión actual se ha probado en Windows; los comandos de macOS y Linux están preparados, pero aún no se han verificado allí.

Para activar Gemini, crea una clave en Google AI Studio y pégala en el botón «Clave de Gemini» de la aplicación. Revisa las cuotas de Google antes de usarlo.
